# STY App Prem — Landing Page Katalog (Tanpa Database)

Isi folder ini:
- `index.html` : halaman utama
- `styles.css` : styling
- `app.js` : logic katalog + modal + redirect WhatsApp
- `data.json` : daftar produk & paket (edit di sini kalau ada update)
- `logo.png` : logo (opsional)

## Cara pakai cepat
1) Upload folder ini ke hosting statis (GitHub Pages / Netlify / Vercel).
2) Ganti nomor WA di `data.json` jika diperlukan.

## Edit produk/paket
Buka `data.json` dan ubah list `products`.
Harga pakai angka (contoh 25000). Website otomatis format Rupiah.
